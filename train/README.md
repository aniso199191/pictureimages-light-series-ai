# Open Chinese LM (prototype)

A small decoder-only Chinese language model trained from scratch on this machine.
The repository ships the training code, the tokenizer, the exact data recipe, and
the resulting weights. Nothing here calls a hosted API at inference time.

## What is in this repository

| Path | Purpose |
|---|---|
| `tokenizer.py` | Character-level tokenizer (special tokens + one token per CJK/ASCII character). |
| `model.py` | Decoder-only transformer: pre-LN, RoPE, SwiGLU, tied embeddings. |
| `prepare.py` | Builds `vocab.json`, `train.bin`, `val.bin` (uint16) from JSONL corpora. |
| `train.py` | Pretraining loop, bf16 autocast, optional 8-bit blockwise AdamW. |
| `sft.py` | Instruction fine-tuning with loss masked to the assistant span. |
| `eval.py` | Validation loss / perplexity and sample generations for a checkpoint. |
| `data/` | Token streams and vocabulary (generated, not source text). |
| `manifest.json` | Dataset provenance: sources, licences, counts, SHA-256. |

## Data

Two kinds of text are used, kept separate so the recipe is auditable:

1. **Pretraining text** — openly licensed reference text (Wikipedia zh, CC BY-SA 4.0;
   Python documentation, PSF licence). Each record carries its source URL and licence.
2. **Instruction data** — question/answer pairs generated by a larger teacher model
   through an OpenAI-compatible API. Every record stores the teacher model name and
   prompt version. This is distillation data, not copied output from a benchmark.

Training data and evaluation data are split by document, so no article appears in both.

## Honest status

- Parameter count, token count, validation loss and sample outputs are reported from
  actual runs; see `RESULTS.md` for the numbers of the shipped checkpoint.
- This is a prototype. It is not competitive with production assistants, and no
  benchmark claims are made without running the benchmark.
- A CPU-only host was used; the model size is limited by memory, not by ambition.

## Quick start

```bash
python prepare.py --train data/wiki_train.jsonl --val data/wiki_val.jsonl --out data
python train.py --steps 4000 --batch 8 --block 512 --out models/base.pt
python eval.py --ckpt models/base.pt --prompt "光合作用是什么"
```
